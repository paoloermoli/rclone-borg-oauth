Informativa sulla privacy

Ultimo aggiornamento: 24 novembre 2026

Rclone BORg è un'applicazione personale utilizzata esclusivamente dal proprietario per trasferire file dal proprio Google Drive al proprio server privato.

Dati utilizzati

L'app accede ai file di Google Drive soltanto dopo l'autorizzazione esplicita dell'utente e unicamente per elencare, leggere e trasferire i file selezionati.

Conservazione

Le credenziali OAuth e la configurazione restano memorizzate localmente sul server privato BORg. Non vengono inviate a un server applicativo esterno.

Condivisione

Rclone BORg non vende, condivide o comunica a terzi i dati ottenuti tramite Google Drive.

Cookie e analisi

Queste pagine non usano cookie, strumenti di profilazione o servizi di analisi.

Revoca dell'accesso

L'utente può revocare l'accesso in qualsiasi momento dalla pagina delle connessioni di terze parti del proprio Account Google.

Contatti

Per informazioni è possibile contattare il proprietario tramite il profilo GitHub @paoloermoli.
